# LandSquare

**LandSquare** es una plataforma web Full Stack diseñada para facilitar la búsqueda, exploración y gestión de terrenos disponibles para compra. Esta aplicación permite a los usuarios filtrar terrenos, guardar favoritos, contactar con vendedores y recibir notificaciones sobre nuevas publicaciones.

## ✨ Características Principales

- 🔍 Exploración y búsqueda avanzada de terrenos con filtros personalizados.
- ❤️ Sistema para guardar terrenos favoritos.
- 🗺️ Visualización de terrenos en Google Maps.
- 📞 Funcionalidad de contacto directo con vendedores.
- 🔐 Registro e inicio de sesión seguro con autenticación JWT.
- 🛠️ Panel de administración con permisos diferenciados para la gestión de publicaciones y cuentas.

## 🧩 Tecnologías Utilizadas

- **Frontend**: React, JavaScript, Bootstrap, HTML5
- **Backend**: Python con Flask
- **Base de Datos**: PostgreSQL
- **Autenticación**: JSON Web Tokens (JWT)
- **Mapas**: API de Google Maps

## 👩‍💻 Rol como Desarrolladora Full Stack

Como desarrolladora Full Stack, me encargué de:

- 💡 Diseñar y desarrollar un sistema seguro de autenticación y registro utilizando JWT, PostgreSQL, Python y Flask.

- 🧑‍💼 Crear un panel de administración con control de permisos para la gestión de publicaciones y cuentas de usuario.
